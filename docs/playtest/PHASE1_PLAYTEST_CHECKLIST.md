# Phase 1 Playtest Checklist

## Opening

- [ ] The game opens without an exception.
- [ ] Both independent battlefields are visible.
- [ ] The HUD identifies P1 Human and P2 Normal AI.
- [ ] The first system wave spawns on both battlefields.

## Defense

- [ ] Build at least three of the four tower types.
- [ ] Upgrade at least one tower.
- [ ] Sell at least one tower.
- [ ] Verify a flying monster is attacked only by a tower that can target flying.
- [ ] Observe boss-bonus feedback through the monster tag and selected tower information.
- [ ] Observe physical or magic resistance tags and the expected damage behavior.

## Offense

- [ ] Send Sheep.
- [ ] Send another unlocked monster type.
- [ ] Verify player-sent monsters enter only the opponent battlefield.
- [ ] Verify a successful send changes Gold and Income.
- [ ] Attempt enough sends to observe the queue limit feedback.

## Completion

- [ ] Play through to Result.
- [ ] Restart Same Seed.
- [ ] Restart New Seed.
- [ ] Record the final state hash.
- [ ] Submit `PHASE1_PLAYTEST_FEEDBACK.md`.
